  2. Block the source IP.
  3. Revert unauthorised changes, such as a changed payout number or disabled two-step verification.
  4. Require two-step verification for the account.
  5. Block or rate-limit the source IP at the firewall, reverse proxy or application while you investigate.
  6. If any sign-in from the IP succeeded, follow the runbook for PRH-AUTH-003.
  7. For the web app, make sure account lockout or progressive delays and bot checks are enabled on the sign-in form.
