## How the paper is built

`cross-dataset-generalisation.md` and the SVG figures in `figures/` are generated by
`scripts/build_paper.py` from the template `src/cross-dataset-generalisation.md.in` and the
committed results in `results/`. The template holds no number of its own; a test fails if it
does, or if the generated files are out of date.

```bash
uv run python scripts/build_paper.py           # regenerate after the results change
uv run python scripts/build_paper.py --check   # what CI runs
```

The LaTeX and PDF versions are built by the **Paper** workflow (`.github/workflows/paper.yml`)
with pandoc and XeLaTeX in the `pandoc/latex` image, pinned by digest, and uploaded as the
`cross-dataset-generalisation` artifact of each run. To build them locally with Docker:

```bash
docker run --rm -v "$PWD/docs/research:/data" -w /data --entrypoint sh \
  pandoc/latex@sha256:505c16cb042a5cb2e7825da6ea7368278e8eb8fc3aff06062e80f790ca00dec8 -c \
  'apk add --no-cache -q font-dejavu && pandoc cross-dataset-generalisation.md --pdf-engine=xelatex \
   -V mainfont="DejaVu Serif" -V sansfont="DejaVu Sans" -V monofont="DejaVu Sans Mono" \
   -V geometry:margin=2.2cm -V fontsize=10pt -o paper.pdf'
```
